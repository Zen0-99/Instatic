# CMS Class Registry

This is a static snapshot of every class-kind style rule currently available in the Instatic CMS. Use it as a reference when designing pages so you reuse existing classes instead of creating duplicates.

**How to read this file:**

- Classes are grouped by category.
- Each entry shows the class name, its CSS properties, and a short description of what it is for.
- If no class matches what you need, create a new one in the `<style>` block of the imported HTML.
